## ✨ Funcionalidades · Features

- 🎬 **Animaciones scroll-driven** con GSAP/ScrollTrigger y scroll suave con Lenis.
- 🧩 **Tarjetas de proyecto** con previsualización en lightbox y microinteracciones con Framer Motion.
- 🧭 **Navegación sincronizada al scroll**.
- 📨 **Formulario de contacto y cotización** con validación en el cliente.
- ♿ **Accesibilidad**: manejo de foco, `aria-live` y soporte a `prefers-reduced-motion` con hooks seguros para SSR.
- 🎨 **Sistema de diseño propio** construido sobre Tailwind CSS v4.

## 🧰 Stack

| Capa | Tecnología |
